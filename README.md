# firstProject

A React Native movie browsing app with navigation for the main experience, movie details, sign-in, registration, and profile settings. The app uses a shared movie context and a tab-based main interface.

## Tech stack

- React Native 0.80 and TypeScript
- React Navigation (stack and tabs)
- Realm
- React Native Paper
- Blur, gradients, and native UI components

## Requirements

- Node.js 18 or later
- React Native development environment configured for Android or iOS
- Xcode and CocoaPods for iOS builds on macOS

## Setup

```sh
npm install
npm start
```

In another terminal, run the app:

```sh
npm run android
# or
npm run ios
```

See the [React Native environment setup guide](https://reactnative.dev/docs/set-up-your-environment) for native toolchain requirements.
