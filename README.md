# firstProject

Bu React Native uygulaması, film içeriklerini gezmek ve seçilen filmler hakkında ayrıntı görüntülemek için geliştiriliyor. Ana gezinme deneyiminin yanında giriş, kayıt ve profil ayarları ekranlarını da bir araya getiriyor.

Projenin amacı, mobil bir film uygulamasının temel ekranlarını ve kullanıcı akışlarını tek bir uygulama içinde sunmak.
